# 给策划的一段简化提示词

把下面这段复制给能够操作本地文件和终端的 AI。复杂流程保存在仓库里，由 AI 自己读取，不需要策划理解 Git 或填写技术参数。

```text
请作为我的团队 AI 能力库助手，接入 https://github.com/WWWWWWWWMWWWWMWW/team-ai-library.git 的 main 分支，自动读取 README.md、AGENTS.md 和 docs/AI_OPERATIONS.md。之后按我的自然语言要求完成接入安装、整理本地资源、查找复用和上传；Git 操作和详细中文说明由你处理，保留原文件，上传先提交待审核。先检查接入情况，再处理我指定的任务。
```

之后直接说本次需求，也可以和提示词一起发送：

- “安装接入这套能力库，检查能不能用。”
- “把我指定文件夹里的工作流和提示词整理后上传，写清中文用法，入库前让我审核。”
- “找一个活动配置检查流程，用它检查我给你的表格。”

需要详细整理本地全部可沉淀内容时，复制 [本地全面整理提示词](LOCAL_CAPTURE_PROMPT.md)。它要求产出完整盘点、逐项说明、配套材料、待补项及建议上传清单，不只给建议。

第一次使用需要本人登录和仓库权限；AI 会提示必要操作，不需要提供密码或令牌。仅说“整理”时默认保留原文件、只生成本地整理结果；明确说“上传”时才投稿。

当前仍仅所有者试用，多人权限尚未开放。接入时核对共享 main 是否包含新版入口与操作手册；若尚未包含，由维护者将经过审核的版本同步到 main。AI 若找不到手册，应报告缺项，不能声称已经按新版流程完成操作。

维护者与 AI 的完整规则见 [AI 自动操作手册](AI_OPERATIONS.md)；具体命令见 [AI 操作指南](AI_GUIDE.md)。
