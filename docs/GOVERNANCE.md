# 权限与审核

## 当前部署事实

已确认：真实仓库为个人账户的私有 GitHub 仓库，目前仅登记 owner 维护者。GitHub 分支保护配置返回 403 并要求升级 Pro；共享分支硬门禁尚未生效。当前选择 `owner_trial` 仅 owner 试用，不购买 Pro、不公开仓库、不邀请成员。

待验证：试用模式部署到可信共享基线，以及真实 PR 投稿、人工核验与合并结果。部署并验证后允许 owner 创建试用请求；不能把本地检查、owner 权限或请求创建视为服务器强制审核。正式多人上传暂未开放。

## 两种部署模式

`deployment_mode` 可选，省略为 `protected`。正式团队协作使用 `protected`，投稿前须核实分支保护及可信必需检查。`owner_trial` 仅适用于 GitHub 私有库的 owner 独占试用；共享基线必须明确采用同一模式，本机设置不能单独启用。两处 remote、shared_branch、platform、publish_mode=request、auto_merge=false 必须一致。

每次 owner 试用远程写入都核实真实私有库；已登录个人账号就是仓库 owner，且具备 admin/push 权限；完整分页协作者只有该 owner，待处理邀请为空；可信共享 members 只登记该 owner 为维护者。无法取得完整证据或任何条件改变即阻断写入，不能用缓存结果替代当次检查。新增任何协作者或邀请后，须切回 `protected`、补齐正式门禁并重新验收才能团队化。

试用结果和请求须明确 `owner_trial=true`、`hard_gate_enforced=false`、`manual_review_required=true`。AI 可以按用户一句明确分享指令准备并创建 PR；不得自动 merge。人核验具体 PR 的完整材料、最新提交及检查结果后，再明确授权合并。当前库不提供试用期间的服务器强制评审保证。

试用只改变适用的部署前提；完整包与出站检查、不可变版本、可信 base 检查器、当前内容和状态绑定继续执行。正式团队协作的以下目标规则，需实际平台验证后才能称已生效。

## 首版边界

publish_mode=request，auto_merge=false。owner 试用只允许唯一 owner 创建请求，并按前述人工核验流程合并。未来 `protected` 团队部署中，普通成员可读仓库、推自己的投稿分支、创建 PR/MR 和治理 issue；共享分支禁止普通直推、强推或删除。维护者审核并合并，治理与状态变更由维护者的 AI 生成提案。

仓库有读权限就可能读到历史；路径约定不能保证保密。需要限制某部分内容的读取时另分仓库，不以 author 目录当保密隔离。

普通投稿只允许自己负责条目的新版本和允许的发现元数据。新条目命名空间取可信账号；现有条目按可信 state.owner_key 授权，不能只看目录名。移交同时更新 meta.owner_key，但保留原作者与 ID。全新条目可附固定初始 state：owner_key 对应可信作者，recommended_version 为本次首版，withdrawn_versions/reviews/verification 为空。发布审批后生效，推荐不等于业务验证。后续 state、成员/策略及移交使用维护者 governance 提案。指南、工具、Schema、配置、测试与 CI 使用维护者 maintenance 提案，按真实差异分类；不可混入条目版本或状态变化，关键入口不能删除。所有角色取可信基线，候选分支自填角色无效。

## 可信检查

身份来自平台，不相信作者自填姓名。检查读取可信 base 的规则与程序，把投稿内容当数据；不能运行投稿分支 tools、payload 或 hook。CI 没有合并凭据。要求的成功检查须核实结果来源，不能仅匹配名称。

审批和检查绑定当前内容；追加提交必须重新审查。owner 试用由人全量核验具体请求并明确授权合并，关闭自动合并，不声称硬门禁已生效；多人协作不能以试用人工流程代替 `protected` 验收。

第一次远程写入前扫描完整材料与提交/请求文字、全部新增提交的中间材料；投稿分支已经是共享。图片和不透明材料先核实分享范围，无法判定先不发。扫描不是绝无秘密的证明。

## 审核与验证

发布审核核对分享范围、包完整性、权限、副作用和依赖，不默认执行脚本。业务验证另记版本、摘要、环境、工具、业务范围和证据；升级不继承旧验证。允许明确标注未验证的能力入库。

维护者日常待办：审核投稿；处理推荐/撤回 issue；核实合并后的内容与状态。成员离开时撤销账号及独立令牌/部署密钥/App 授权，移交条目但保留 ID 和原作者。不能只删除 members 记录就称权限已失效。
