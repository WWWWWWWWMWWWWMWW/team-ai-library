# 本地能力全面整理提示词

复制下方整段给可以操作本地文件的 AI。可直接在末尾加“整理这个文件夹：……”；不写路径时，AI 先使用当前明确的业务项目范围，无法确定就列出已识别项目让你选名称或编号。此提示词创建整理任务，不授权全盘读取或自动上传。

```text
请帮我全面盘点并详细整理本地所有值得沉淀给策划团队复用的 AI 能力，不要只找现成 Skill，也不要只给建议。

如果我说“盘点我的 Codex”，盘点对象已明确：自动识别 CODEX_HOME（没有时用当前用户 .codex）和 .agents/skills，整理技能、提示词、工作约定、自动任务和本机任务记录中形成的方法与案例；不先索要业务文件夹路径，不读取登录凭据或私人配置，不复制完整聊天。共享指南缺失也继续本地整理。

从当前明确的业务项目和我指定的文件夹开始，不把能力库接入目录当业务项目。没有给路径时，先根据当前会话已提供的工作区与项目信息识别候选；范围仍不明确就列出项目名称让我选编号或“以上全部”，不要首先要求我手写完整路径。接入团队能力库 https://github.com/WWWWWWWWMWWWWMWW/team-ai-library.git，读取共享 main 的 AGENTS.md、docs/AI_OPERATIONS.md 和 docs/LOCAL_CAPTURE.md，按规则实际完成本地整理。仓库或新版指南暂时不可读时，说明缺项，仍按以下要求整理本地草稿，不冒充已接入或已通过库校验。

请覆盖现成技能、常用提示词、完整工作流、自动化脚本、表格和文档模板、检查清单、配置与排错方法、资源处理方法、分析与研究方法，以及成功案例、失败经验和容易遗漏的隐性步骤。结合文件实际内容、相互依赖和项目内可读取的变更记录提炼经验；图片、PDF、表格等不能只看文件名，需要用可用工具检查内容。工具不支持的材料明确列为未检查，不猜内容。

先递归建立文件清单，再逐项或分批检查，持续记录进度。不要只挑几项代表内容就结束，也不要为了数量把同一流程拆成一堆条目。完整清单中记录每项已检查、跳过、不可读取及对应原因，另统计未完成项。

每项值得沉淀的内容都用详细中文说明：它是什么、解决什么问题、谁在什么情况下能用、哪些情况不适用、需要准备什么、具体步骤、输出是什么、怎么检查结果、一个脱敏示例、依赖和权限、实际验证与未验证部分、来源和版本、踩过的坑，以及还缺什么。提炼通用方法，项目专用配置另列，不编造效果或节省时间。

查重并区分“可直接复用”“需要少量补齐”“项目专用参考”“暂不建议共享”；同内容不同版本保留来源和差异，不覆盖或删除原件。复制必要材料到独立草稿目录，生成完整能力草稿；不搬走原文件，不执行未知脚本，不读取未指定的个人聊天、账号配置或凭据。

请实际产出：①盘点总览与覆盖统计；②逐项来源清单；③分类能力目录；④每项能力的详细中文说明及必要配套材料；⑤缺项与未检查清单；⑥按复用价值、成熟度和补齐成本排序的建议上传清单。范围较大就分批完成并保留继续整理记录，不因没有仓库权限停止本地工作。

本次先完成本地整理，不自动上传；之后我说“上传这些”时，再按仓库规则校验并提交待审核请求。
```

AI 执行细则见 [本地能力全面盘点与整理](LOCAL_CAPTURE.md)。提示词本身也包含本地降级流程；新版仓库文档尚未共享或无仓库权限时，仍可完成本地盘点和草稿，仓库校验、查重与投稿的缺项须据实说明。
