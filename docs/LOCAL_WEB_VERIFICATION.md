## 复测方式

普通使用不需要浏览器测试依赖。开发者复测时准备 Playwright 和可用 Chrome，生成真实页面及合成夹具：

```sh
python3 tools/build_catalog.py --with-pending
python3 -m tests.local_web_fixtures .teamlib-workspace/web-fixtures
node tests/test_local_web_browser.cjs docs/local-library.html .teamlib-workspace/web-fixtures .teamlib-workspace/web-evidence
```

非标准依赖路径可通过 `TEAMLIB_PLAYWRIGHT` 指向 Playwright 模块、`TEAMLIB_BROWSER` 指向测试浏览器可执行文件。生成的截图和 `browser-report.json` 写入最后指定的本地证据目录，不上传个人业务原文。
