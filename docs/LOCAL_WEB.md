# 本地网页的打开与使用

这是团队能力库的主要入口。克隆公开仓库后，直接双击仓库根目录醒目的 `00-打开团队能力库网页.html`，即可浏览嵌入的能力目录与完整文本说明；它会自动打开 `docs/local-library.html`。无需安装 `gh`、登录 GitHub、启动服务、安装前端依赖或联网加载页面资源。

## 策划怎么用

1. 打开首页先看五类内容：**Skill 技能、工具、提示词、方法与流程、案例与经验**。默认展示团队上传内容；平台生成的示例在“示例内容”里单独查看。
2. 直接搜索你要做的事，例如“审策划案”“整理会议”“查漏项”。每条结果只展示中文名称、用途、作者、来源和分类；点击“查看详情”再看输入、产物、版本、依赖和限制。
3. 选定具体版本，点“复制使用指令给 AI”，粘贴给自己的 AI。AI 会按真实仓库规则接入、实时检查状态与依赖、下载材料，再完成当前任务。
4. 想沉淀经验时，打开“沉淀我的能力”：盘点 Codex、整理指定资料或分享本次成果。复杂整理与 Git 操作由 AI 处理，策划不需要填写分支、提交或合并信息；普通查阅者可以忽略这个维护入口。三个按钮默认都是普通操作样式，只有确认写入剪贴板后，被点击的按钮才短暂显示绿色“已复制”；复制失败会继续打开手动复制框。补充目标输入框默认收起，需要指定资料时再展开。

网页只负责浏览和生成任务指令；内容保存在团队 Git 仓库，页面本身不读取本机文件、聊天、账号或令牌。当前仓库中的示例明确标注为平台生成示例，未代表真实团队业务效果。

## 复制失败怎么办

只有浏览器确认复制成功，页面才显示“已复制”。不支持或拒绝剪贴板访问时会打开手动复制框：点“全选”，使用 ⌘C（Mac）或 Ctrl+C（Windows/Linux），再粘贴给自己的 AI。关闭框不会假称复制完成。

## 版本与更新

- 首页按能力合并展示，能力数与版本数分开。没有明确推荐版本时，先选择具体版本再使用；不默认推荐最大版本。
- 包含历史和停用版本用于查阅。撤回、作废或依赖停用版本不能生成普通使用指令，只能让 AI 查明原因和安全替代版本。
- 详情可跳转本快照中的准确依赖版本。验证记录只对应当前材料标识，展示覆盖范围和失败记录，不外推到所有任务。
- 顶部显示本地快照来源和生成时间。刷新浏览器只重读当前文件；“让 AI 更新”复制维护任务，取得新的共享内容并重新生成后，再重开页面。

## AI 如何维护

从仓库根目录运行：

```sh
python3 tools/build_catalog.py --with-pending
```

同时生成 `docs/CATALOG.md`、`docs/catalog.json` 和 `docs/local-library.html`。目录、README、可展示的文本入口来自同一新鲜共享快照，不混入当前分支的处理中正文。前置读取或校验失败时保留现有文件；每个生成文件分别原子替换，不承诺三个文件组成一个事务。旧 HTML 始终携带自己的完整快照，不依赖旁边的 JSON。

网页单个文本展示上限为 128 KiB，总 HTML 上限为 5 MiB。脚本、二进制、不安全编码和超限正文会显示原因，既不执行也不静默截断；完整版本材料由 AI 按规则获取。已有手工 HTML 会阻断生成，不能静默覆盖。维护者修改模板后重跑生成，不直接手改生成文件中的业务内容。

## 当前适用边界

页面不会增加 Git 权限，也不会提供服务器强制审核门禁；上传和真实业务效果仍须单独验收。首次使用时先打开网页，再按具体能力的入口说明操作。页面的浏览器验收结果见 [网页验收记录](LOCAL_WEB_VERIFICATION.md)，不从自动测试推断未经检查的环境。
