# 本地网页的打开与使用

这是团队能力库的本地阅读入口。双击本仓库的 `docs/local-library.html`，即可浏览嵌入的能力目录与完整文本说明；无需启动服务、安装前端依赖或联网加载页面资源。文件可单独打开，但包含内部资料，仍按团队授权范围使用。

## 策划怎么用

1. 打开首页先看四个主题：“方法与流程”“提示与工具”“案例与经验”“资料与研究”。主题卡片显示当前能力数，下面的能力卡片还会直接显示作者、来源和适用范围。在“找能力”输入本次工作，例如“审策划案”“整理会议”“查漏项”。搜索支持多个关键词；标题、别名、说明、输入产物和范围均可检索。没有内容时会给出真实空结果。
2. 打开详情，先看输入产物、适用限制、具体方法与业务验证。推荐版本只是库中的明确选择，不代表效果已经验证；内置示例会明确标记。
3. 选择明确版本，点“复制使用指令给 AI”，粘贴到自己的 AI。AI 会按真实仓库规则接入、实时检查状态与依赖、下载材料，再完成当前任务。网页复制不代表已执行。
4. 想沉淀经验时，打开“沉淀我的能力”：盘点 Codex、整理指定资料或分享本次成果。前两项只整理本地草稿；分享指令针对明确选择的成果做脱敏、详细中文说明、自动校验并入库，检查失败或内容变化时暂停。

“让 AI 保存这项能力”是将材料保存到库配置的目录，当前不表示注册为原生 Codex Skill。任务原文只在本次页面内存中使用，不写入文件、网址或本地存储。页面也不读取本机文件、聊天、账号或令牌。

## 复制失败怎么办

只有浏览器确认复制成功，页面才显示“已复制”。不支持或拒绝剪贴板访问时会打开手动复制框：点“全选”，使用 ⌘C（Mac）或 Ctrl+C（Windows/Linux），再粘贴给自己的 AI。关闭框不会假称复制完成。

## 版本、处理中请求与更新

- 首页按能力合并展示，能力数与版本数分开。没有明确推荐版本时，先选择具体版本再使用；不默认推荐最大版本。
- 包含历史和停用版本用于查阅。撤回、作废或依赖停用版本不能生成普通使用指令，只能让 AI 查明原因和安全替代版本。
- 详情可跳转本快照中的准确依赖版本。验证记录只对应当前材料标识，展示覆盖范围和失败记录，不外推到所有任务。
- “处理中请求”是生成时的平台请求快照，与已入库目录分开。需要登录有权限的 GitHub 账号查看私有请求；网页和 AI 工具的登录状态可能不同。
- 顶部显示本地快照来源和生成时间。刷新浏览器只重读当前文件；“让 AI 更新”复制维护任务，取得新的共享内容并重新生成后，再重开页面。

## AI 如何维护

从仓库根目录运行：

```sh
python3 tools/build_catalog.py --with-pending
```

同时生成 `docs/CATALOG.md`、`docs/catalog.json` 和 `docs/local-library.html`。目录、README、可展示的文本入口来自同一新鲜共享快照，不混入当前分支的处理中正文。前置读取或校验失败时保留现有文件；每个生成文件分别原子替换，不承诺三个文件组成一个事务。旧 HTML 始终携带自己的完整快照，不依赖旁边的 JSON。

网页单个文本展示上限为 128 KiB，总 HTML 上限为 5 MiB。脚本、二进制、不安全编码和超限正文会显示原因，既不执行也不静默截断；完整版本材料由 AI 按规则获取。已有手工 HTML 会阻断生成，不能静默覆盖。维护者修改模板后重跑生成，不直接手改生成文件中的业务内容。

## 当前适用边界

仓库仍为 owner 独占试用；页面不会增加 Git 权限，也不会提供服务器强制审核门禁；当前上传由 AI 自动检查并入库。首次团队多人使用、其他成员操作系统、原生 Skill 导入和真实业务效果仍须单独验收。页面的浏览器验收结果见 [网页验收记录](LOCAL_WEB_VERIFICATION.md)，不从自动测试推断未经检查的环境。
