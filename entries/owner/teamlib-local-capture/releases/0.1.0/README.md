# 团队能力库本地捕获

## 解决什么问题

按共享指南完成独立取库、环境和权限检查、元数据盘点、内容提炼和本地草稿，保留上传边界。

## 适用与不适用

- 输入：共享仓库、Codex 素材位置、允许读取的材料
- 输出：来源清单、能力草稿、进度和阻塞报告
- 适用范围：能力库接入、本地能力盘点、上传前准备
- 不适用范围：未经授权上传、读取凭据或完整聊天
- 工具要求：Codex、Git、Python 3
- 副作用与任务权限：read_only、local_generate；远程写入与发布需单独授权。

## 怎么复用

阅读 `payload/instructions.md`，按准备、证据整理、执行、验证、报告顺序运行；每次使用都记录实际环境和未验证项。

## 依赖

无团队能力依赖；外部工具和业务项目按当前任务现场核对，不自动安装。

## 示例与判断依据

使用团队内部合成任务按流程走一遍，检查输入、步骤、产物、证据和失败处理是否完整。本次只验证材料结构和出站范围，业务效果未验证。

## 已知限制

历史案例中的具体项目规则、路径和版本不能自动外推到其他项目；需要当前源码、配置和运行时证据时，必须重新检查。

## 来源与改动

- 原作者：owner（团队内部 Codex 工作方法）
- 原始来源：本机会话索引和本地盘点草稿
- 改编来源：无
- 本版变化：将重复出现的方法整理为独立团队流程；未复制原始聊天和完整业务项目。
