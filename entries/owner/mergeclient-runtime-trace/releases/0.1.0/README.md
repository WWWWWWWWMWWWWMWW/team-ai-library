# MergeClient 源码到运行时追踪

## 解决什么问题

将截图或录屏沿请求、客户端调用、服务端分支、配置和资源链追到实际运行时行为。

## 适用与不适用

- 输入：截图/录屏、请求信息、源码路径、配置和资源
- 输出：证据链、影响字段、运行时验证计划
- 适用范围：活动配置、Prefab/资源排查、客户端服务端联动
- 不适用范围：只看截图下结论、把单项目规则外推
- 工具要求：Codex、filesystem.read、项目工具
- 副作用与任务权限：read_only、local_generate；远程写入与发布需单独授权。

## 怎么复用

阅读 `payload/instructions.md`，按准备、证据整理、执行、验证、报告顺序运行；每次使用都记录实际环境和未验证项。

## 依赖

无团队能力依赖；外部工具和业务项目按当前任务现场核对，不自动安装。

## 示例与判断依据

使用团队内部合成任务按流程走一遍，检查输入、步骤、产物、证据和失败处理是否完整。本次只验证材料结构和出站范围，业务效果未验证。

## 已知限制

历史案例中的具体项目规则、路径和版本不能自动外推到其他项目；需要当前源码、配置和运行时证据时，必须重新检查。

- 改编来源：无
