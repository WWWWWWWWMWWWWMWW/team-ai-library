# 工作知识库检索与单向收录

## 解决什么问题

从明确项目和来源检索工作知识，保留来源和指纹，经 prepare/apply 流程单向收录到知识库。

本版本来自本机 Codex 自定义技能，保留原始入口说明与必要配套材料。

## 适用与不适用

- 输入：项目或主题、知识库配置和来源文档
- 输出：检索结果、来源指纹、候选收录记录
- 适用范围：工作知识检索、知识条目更新、来源追溯
- 不适用范围：直接修改数据库、未授权改写原始知识
- 工具要求：Codex、Python 3、Obsidian 文件库
- 副作用与任务权限：read_only、local_generate、project_write；远程写入、发布、后台导入和外部发送仍需单独授权。

## 怎么复用

1. 先阅读 `payload/SKILL.md`，确认触发条件、输入格式和边界。
2. 按入口说明准备完整材料；需要配套文件时从 `payload/` 的原相对路径读取。
3. 按正文步骤执行，逐项记录产物、检查结果和未验证项；未完成业务运行验证时不得写成已通过。

## 示例与判断依据

使用一个不含未授权外发动作的团队业务任务，提供完整输入，按“准备→执行→核查→记录未验证项”运行。实际业务试用由使用者在本地记录；本次上传只验证材料包结构和出站内容，未宣称业务效果。

## 已知限制与失败处理

- 本版只包含列出的必要文件；未列入的缓存、压缩包、二进制和私有运行环境不在包内。
- 脚本未在本次投稿过程中执行；业务结果、运行时效果和外部服务状态均未验证。
- 出现输入缺失、版本不兼容或权限不足时保留原材料，停止在本地草稿并记录阻断原因。
