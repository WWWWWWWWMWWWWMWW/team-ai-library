# 概念图质量量表

满分 100，80 分及以上且无硬性失败项才可交付为“通过”。

| 维度 | 分值 | 检查重点 |
|---|---:|---|
| 项目风格一致性 | 25 | 圆润手绘、奶油面板、粗描边、主题顶框、按钮与关闭方式是否像同一产品 |
| 信息层级与可读性 | 20 | 一眼能否识别主题、当前目标、进度与主 CTA；背景是否抢信息 |
| 页面原型正确 | 15 | 是否服务该活动的首要行为，而非误用弹窗、礼包页或无关棋盘 |
| 组件与布局一致性 | 15 | 间距、对齐、卡片、进度、奖励图标和按钮是否形成统一系统 |
| 内容真实性 | 15 | 是否只使用用户提供的玩法、文案、数值和奖励；占位符是否明确 |
| 移动端适配合理性 | 10 | 竖屏安全边距、点击目标、关闭/帮助位置、底部 CTA 是否可靠 |

## 硬性失败项

- 生成了用户未提供的奖励数量、价格、概率、计分规则或倒计时。
- 主操作不可识别，或页面首要行为与需求不一致。
- 大量伪文字、乱码或关键文字无法阅读。
- 重要元素贴边、被裁切、被刘海/系统区遮挡，或按钮明显过小。
- 把入口小图、领奖弹窗、礼包页直接放大成主活动页面。
- 混入真实品牌水印、设备外壳、鼠标指针、调试版本号或无关角色。

## 复审顺序

1. 先检查硬性失败项。
2. 从 1 米外缩略查看，确认主题、目标和 CTA 的顺序。
3. 放大检查关键文字、按钮、图标、边缘和重复元素。
4. 与本轮 3～5 张参考图逐项比较系统骨架，不要求复制主题素材。
5. 每轮只修一个主问题，例如“顶部太重”或“奖励轨道不清”，避免整体漂移。
