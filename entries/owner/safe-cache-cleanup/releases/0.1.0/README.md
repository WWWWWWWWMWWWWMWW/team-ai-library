# 安全清理与可再生缓存边界

## 解决什么问题

在保留 Git/LFS 和用户材料的前提下，确认进程与缓存状态，只清理可再生目录并做前后复核。

## 适用与不适用

- 输入：HEAD/status、进程、目录大小、远端校验结果
- 输出：清理前后证据、保留项、风险和复核结果
- 适用范围：本机磁盘维护、可再生缓存清理
- 不适用范围：直接删除 .git/lfs、删除模型或源码、未验证远端就清理
- 工具要求：Codex、Git、git-lfs、macOS shell
- 副作用与任务权限：read_only、project_write、local_generate；远程写入与发布需单独授权。

## 怎么复用

阅读 `payload/instructions.md`，按准备、证据整理、执行、验证、报告顺序运行；每次使用都记录实际环境和未验证项。

## 依赖

无团队能力依赖；外部工具和业务项目按当前任务现场核对，不自动安装。

## 示例与判断依据

使用团队内部合成任务按流程走一遍，检查输入、步骤、产物、证据和失败处理是否完整。本次只验证材料结构和出站范围，业务效果未验证。

## 已知限制

历史案例中的具体项目规则、路径和版本不能自动外推到其他项目；需要当前源码、配置和运行时证据时，必须重新检查。
