# 游戏计费点批量生成

## 解决什么问题

根据商品 ID、中文名和 Cash 价格，按已有后台模板生成华为、国服 GM、港澳台 GM 的计费点批量文件，并执行重复 ID 与字段回读检查。

本版本来自本机 Codex 自定义技能，保留原始入口说明与必要配套材料。

## 适用与不适用

- 输入：商品 ID、名称和 Cash 价格、后台导出模板
- 输出：批量导入文件、ID/行数/字段核对结果
- 适用范围：新增商品批量准备、同价模板复制、多后台格式转换
- 不适用范围：修改已有商品、缺少模板、直接操作后台
- 工具要求：Codex、Python 3
- 副作用与任务权限：read_only、local_generate；远程写入、发布、后台导入和外部发送仍需单独授权。

## 怎么复用

1. 先阅读 `payload/SKILL.md`，确认触发条件、输入格式和边界。
