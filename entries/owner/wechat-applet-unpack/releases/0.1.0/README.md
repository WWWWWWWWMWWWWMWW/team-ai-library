# 微信小程序本地包研究

## 解决什么问题

在 macOS 固定缓存路径内，对获得授权的小程序缓存进行收集、解包和 Lua 提取，保留版本范围与质量统计。

本版本来自本机 Codex 自定义技能，保留原始入口说明与必要配套材料。

## 适用与不适用

- 输入：合法 wx ID、macOS 固定缓存路径、授权缓存
- 输出：解包目录、Lua 提取结果、summary 统计
- 适用范围：本地授权研究、Unity+xLua 资源分析、版本对比
- 不适用范围：越界搜索、覆盖既有结果、无授权采集
- 工具要求：Codex、macOS shell、Python 3、Node.js
- 副作用与任务权限：read_only、local_generate；远程写入、发布、后台导入和外部发送仍需单独授权。

## 怎么复用

1. 先阅读 `payload/SKILL.md`，确认触发条件、输入格式和边界。
2. 按入口说明准备完整材料；需要配套文件时从 `payload/` 的原相对路径读取。
3. 按正文步骤执行，逐项记录产物、检查结果和未验证项；未完成业务运行验证时不得写成已通过。
